FINANCE — PWA

Arquivos:
- index.html
- manifest.webmanifest
- sw.js
- icons/

Para publicar:
1. Envie estes arquivos para um repositório público no GitHub.
2. Ative GitHub Pages para a branch principal e a pasta raiz.
3. Abra a URL HTTPS do GitHub Pages no Safari do iPhone.
4. Safari > Compartilhar > Adicionar à Tela de Início.

Depois de instalado, o Finance abre como um app, sem a barra normal do Safari.

Observação:
Esta versão usa os dados financeiros atuais embutidos no dashboard. Não coloque dados bancários/senhas reais em um repositório público.
